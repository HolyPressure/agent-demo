# AI 智能应用开发流程

> 技术栈：FastAPI + LangChain（+ 可选 LangGraph）+ uv + DeepSeek  
> 目标：从可运行的聊天骨架，逐步做成带工具、记忆、RAG 的智能后端（后续可接前端）。

本文档是本项目的**开发路线图**（阶段目标与验收）。  
**具体操作步骤、每步「为什么」、以及实现记录**见：[`Agent开发实现步骤.md`](Agent开发实现步骤.md)。  
每完成一个阶段，把对应勾选框打上 `[x]`。

## 总体原则

1. **先跑通，再变强**：先真实大模型对话，再工具、记忆、RAG。
2. **分层不越界**：
   - `api/`：只负责 HTTP（参数校验、流式响应、状态码）
   - `agents/`：组链 / 建图 / 调用模型
   - `tools/`：可被 Agent 调用的工具
   - `rag/`：检索与知识库
   - `memory/`：会话与长期记忆
   - `core/`：配置、公共依赖
3. **密钥不进仓库**：只提交 `.env.example`，本地用 `.env`。
4. **每阶段可演示**：阶段结束时接口或脚本能独立验证。

## 阶段一：接通真实大模型（DeepSeek）

**目标：** `POST /chat/` 返回 DeepSeek 真实回答，不再是模拟文案。  
**详细步骤与为什么：** 见 [`Agent开发实现步骤.md`](Agent开发实现步骤.md) 阶段 1。

### 任务清单

- [ ] 复制 `.env.example` → `.env`，填写 `DEEPSEEK_API_KEY`（及可选的 `DEEPSEEK_MODEL`）
- [x] 安装 `langchain-deepseek`，在 `agents/chat_agent.py` 用 `ChatDeepSeek` 调用模型
- [x] 使用 `agents/prompts.py` 中的 `SYSTEM_PROMPT` 作为系统提示
- [x] 确认无密钥时仍有友好提示；有密钥时正常对话
- [ ] 用 `/docs` 或 curl 验证一轮问答

### 验收标准

- 配置正确密钥后，同一问题两次回答可变化（非固定模板字符串）
- 未配置密钥时，接口不崩溃，返回明确提示

### 涉及文件

- `backend/agents/chat_agent.py`
- `backend/agents/prompts.py`
- `backend/core/config.py`
- `.env` / `.env.example`

## 阶段二：流式输出（SSE）

**目标：** 前端可逐字显示回答，提升体验。

### 任务清单

- [ ] 新增流式接口，例如 `POST /chat/stream`
- [ ] Agent 侧使用模型 `.stream` / `.astream`
- [ ] FastAPI 用 `StreamingResponse` 或 SSE 推送 token
- [ ] 保留原有非流式 `POST /chat/`，方便调试

### 验收标准

- 流式接口能持续输出片段直至结束
- 非流式接口行为与阶段一一致

---

## 阶段三：会话与记忆

**目标：** 同一会话内多轮对话能记住上下文。

### 任务清单

- [ ] Schema 增加 `session_id`（或 `thread_id`）
- [ ] 在 `memory/` 实现简易会话存储（先内存；再可换 Redis / 数据库）
- [ ] Agent 组装历史消息再调用模型
- [ ] （可选）引入 LangGraph checkpointer，为后续复杂图做准备

### 验收标准

- 同一 `session_id` 下，后一轮能引用前一轮信息
- 不同 `session_id` 互不串话

---

## 阶段四：工具调用（Agent Tools）

**目标：** 模型能按需调用工具（计算器、时间、业务 API、搜索等）。

### 任务清单

- [ ] 在 `tools/` 实现 1～2 个示例工具（如当前时间、简单计算）
- [ ] 用 LangChain Agent / LangGraph 绑定工具并执行
- [ ] API 层可返回「用了哪些工具」的调试信息（开发环境）
- [ ] 工具失败时有降级与错误信息

### 验收标准

- 提问「现在几点」或「计算 17*19」时会走工具，而不是纯瞎编

---

## 阶段五：RAG 知识问答

**目标：** 基于自有文档回答，减少幻觉。

### 任务清单

- [ ] 确定知识来源（本地 `docs/`、上传文件等）
- [ ] `rag/`：加载 → 切分 → 向量化 → 检索
- [ ] 选向量库（开发期可用内存 / Chroma 等）
- [ ] Agent 回答前先检索，把片段注入提示词
- [ ] （可选）管理接口：上传文档、重建索引

### 验收标准

- 对文档内事实提问，回答能对应到来源片段
- 文档外问题会明确表示不确定或未找到
